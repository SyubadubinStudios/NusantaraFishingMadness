# Nusantara Fishing Madness 0.3.0-preview.1

Created by Ariana Mischa Fadhila, Syubadubin Studios.

## New in this preview

- Rodin illustrations for launch, regional loading, promotional documentation and the application icon.
- Cinematic About page with scrolling credits, pause/replay and reduced-motion support.
- Eleven distinct character meshes, 58 catch/boss exports, 14 regional music loops and boss/DJ themes.
- Snorkeling, spear/hand catching, character-specific interactions, hidden quests, trophy displays and regional props.
- Native installers for Windows x64, Linux x64, macOS Apple Silicon and macOS Intel. The .NET runtime is included.

**ID:** Ilustrasi pembuka/loading, kredit bergulir, aset karakter/tangkapan, musik wilayah, fitur gameplay, serta installer tiap platform tersedia dalam preview ini.

## Installation

- Windows: run `*-win-x64-setup.exe`; it installs for the current user. Existing script-based preview installations should be uninstalled before using the new installer. Saves are stored separately.
- Ubuntu/Debian x64: `sudo apt install ./NusantaraFishingMadness-0.3.0-preview.1-linux-x64.deb`. Remove with `sudo apt remove nusantara-fishing-madness`.
- macOS: choose the `.pkg` matching Apple Silicon (`osx-arm64`) or Intel (`osx-x64`). The game installs into Applications. Remove the app bundle to uninstall; saves are stored separately.
- Verify downloads against `SHA256SUMS`.

## Preview limitations

Installers are not signed by a trusted publisher. The macOS app has an ad-hoc signature and is not notarized; Gatekeeper may require approval in Privacy & Security. Windows may show an unknown-publisher prompt. Only proceed for a download you intended to obtain from this repository.

Windows graphics/gameplay have local native evidence. CI validates builds, rules, HTTP multiplayer and installation on the runner operating systems; it does not establish Linux/macOS graphical runtime compatibility. The UHD 620 low-power coastal baseline is approximately 29.7 FPS, with slow initial GPU setup. Some catch models remain procedural and animations/NPC interactions still need polish. See `docs/design-alignment.md` and `PLAN.md` for the remaining work.
